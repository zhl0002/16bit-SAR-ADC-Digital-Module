# 顶层集成与签核准备

`cali_logic` 已完成模块级前后端实现，现有紧凑版可用于 ADC 顶层集成。本项目汇总各阶段的验收范围和待完成事项，明确上电校准、正常转换以及整片流片签核分别需要哪些证据。基线为 ICC2 的 `cali_logic/packed_final` 与配套门级网表、约束及工程版 STA 报告。

## 八个阶段的待补工作

| 阶段 | 当前结果 | 待补工作与依赖 |
| --- | --- | --- |
| [RTL 设计与验证](../02-RTL-Design/) | 7 份 testbench、9 组配置通过 | 恢复 URG 代码覆盖率汇总，验证未覆盖的保护分支。实际比较器握手、CDC/RDC 和选定的顶层参数需要在集成环境验证。 |
| [逻辑综合](../03-Logic-Synthesis/) | 以 SMIC18 `typical` 库和 10 ns 试约束完成标准单元映射 | 由 ADC 顶层给出正式周期、时钟不确定性、输入输出延时、驱动和负载。用正式条件复核综合结果及功耗。 |
| [形式等价验证](../04-Formal-Verification/) | 综合后 706 点、扫描插入后功能模式 706 点、紧凑版布线后 707 点通过 | 现有版本的等价报告可随同模块交付。网表或配置发生功能相关改动时，复查受影响的版本。 |
| [可测性设计](../05-Design-for-Test/) | 584 个扫描单元，349 个固定型故障向量在扫描插入网表上回放通过，测试覆盖率为 99.88% | 已核对最终布线网表与布线前的扫描单元串接顺序一致。待用最终布线网表回放，结合顶层测试模式确认扫描端口、测试时钟与生产测试的故障模型。 |
| [布局布线](../06-Place-and-Route/) | 紧凑版 339.72 × 337.56 µm。ICC2 复开检查为 0 开路、0 布线违规 | 用正式 RC 和时序约束复核收敛。与 ADC floorplan 确认数字模块面积预算，当前尺寸仍超过原定 100 × 100 µm 目标。 |
| [物理验证](../07-DRC-and-LVS/) | 块级 LVS 为 `CORRECT`。DRC 剩余结果集中在芯片边界和整体金属密度 | 等顶层边界与金属填充确定后复查整片。已有 `BD_2a` 计数达到报告上限，ERC 的 `TIELO` 路径也需落实处理结论。 |
| [寄生参数提取](../08-Parasitic-Extraction/) | 工程 Calibre xRC 已完成 PDB 验证，现有 STA SPEF 由 ICC2 导出 | 取得与目标金属选项匹配的签核提取规则、层映射及所需 RC 角，再提取最终版图。 |
| [静态时序分析](../09-Static-Timing-Analysis/) | 10 ns、`typical`、功能模式下已约束的 `cal_clk` 路径组无违例，最差 Setup +0.0136 ns、Hold +0.3094 ns | 补齐正式寄生和约束，再分析规定的工艺、电压、温度角及工作模式。现有报告有 9 个输入缺时钟相关延时、12 个端口缺外部驱动模型、121 个输出端点缺最大延时约束。 |

**工艺资料的主要缺口是签核级 PEX。** 本地已有 SMIC18 `fast`、`typical`、`slow` 标准单元时序库。对应当前 **1P6M 9K** 金属选项的签核提取规则尚待取得并确认。现有的 Calibre `CMAX`、`CMIN`、`TYPICAL` 规则目录中的 `rules.C` 和 `rules.R` 为空，另有非空原厂提取文件对应不同的顶层金属选项。工程 TLU+ 与试算 Calibre 规则已用于初步分析。

## ADC 顶层原理图需要确定的接口

需求为上电执行一次校准，校准成功后恢复正常转换。以下工作可从 Virtuoso 原理图级数模联合仿真开始。

| 接口 | 当前依据 | 顶层要给出的结果 |
| --- | --- | --- |
| 上电与控制权 | `rst_ni`、`cal_go_i`、`cal_release_ready_o`、`weights_valid_o` 和 `error_o` 已定义。已有一次性 POR 的独立仿真 | 确定供电、参考和时钟稳定后的复位释放及启动顺序。明确校准时比较器、开关和 CDAC 的控制属主，并验证成功回切及失败后的安全停靠。 |
| 比较器请求与回读 | 模拟侧已有 `CLK_EVAL`、`COMP/COMN` 和行为模型 `READYN`。既有正常转换波形显示 `READYN` 高电平约 1.8 ns | 确定 `cmp_req_o` 到评估/复位的时序、判决极性、事件与数据保持及跨域交接。验证每个请求只产生一次有效的 `cmp_done_i`，采样时 `cmp_result_i` 稳定。 |
| CDAC 与电平转换 | 已有 1.8 V → 3.3 V level shifters。参考开关的第 19、20 路共用 `FLASH_EN` | 确认 `cal_bp_sel_a_o`、`cal_bp_sel_b_o` 的侧别、位序及 `00/01/10` 到参考选择的映射。确定 `phase_o` 对采样、建立和评估的作用。核对高位逐位接管、开关非交叠和停靠状态。 |
| 权重与正常转换 | RTL 提供 20 项 32 位权重，含 8 位小数。现有模拟重构使用固定权重 | 确定读权重的模块、读取和生效时机、位序、尺度和增益。验证校准权重确实进入正常转换及输出重构。 |
| 正式时钟与约束 | 正常转换测试台使用 200 ns 帧周期，模块 STA 使用 10 ns 试分析周期。当前模块实现的 `CMP_TIMEOUT` 为 1024，`adc_digital_top` 源码默认传入 65536 | 确定 `clk_i` 来源和周期、最坏比较与建立时间、超时配置、时钟域和复位域关系，再以实测预算编制正式 SDC。确认最终顶层使用的参数与交付版一致。 |

首个联合仿真验收用例是**完成一次实际校准比较**。依次核对参考选择、比较器评估、完成事件和判决采样。之后验证完整上电校准、权重生效、正常转换及异常退出。

## ADC 顶层版图完成后的验收

| 检查 | 要确认的结果 |
| --- | --- |
| 整片 DRC、LVS、ERC | 顶层新增连线、模块边界、供电连接、金属填充与密度符合工艺要求。复查天线规则与模块交接时记录的待处置项。 |
| 签核级 PEX | 对最终版图提取寄生，得到时钟、比较器回读和 CDAC 控制的实际互连延时、负载及耦合。 |
| 正式 STA 与接口时序 | 用正式 SDC、规定工作模式和工艺角、签核寄生检查 Setup/Hold。用数模后仿真确认比较器判决保持和 CDAC 建立裕量。 |
| 供电、参考与后仿真 | 核对压降、参考扰动和电流密度，回标寄生验证校准耗时及校准后的转换精度、速度和功耗。 |
| 最终归档 | 固定交付版图及对应网表、约束、寄生参数和报告。核对每项验收的版本、范围、结论与剩余问题处置。 |

现有模块报告可在版图版本、规则和接口条件吻合时引用。整颗 ADC 的流片签核以最终顶层版图为对象。
