# 16位 SAR ADC数字模块

本项目包含八个 Verilog 模块、三个中文阅读指南和工程说明。当前版本已通过整机静态编译与参数展开检查，功能及时序等价性需要后续仿真确认。

- [SAR ADC数字模块源码阅读指南](<SAR ADC数字模块源码阅读指南.md>)
- [cali_logic接口、信号、常量与参数阅读指南](cali_logic接口、信号、常量与参数阅读指南.md)
- [cali_logic源码阅读指南](cali_logic源码阅读指南.md)


本目录是纯数字版本。校准专用 SAR 完整保留在 cali_logic 内部，输出数字比较请求、正负 CDAC 选择码及阶段命令；不实现开关驱动、电平转换、比较器物理时钟或模拟采样/AZ波形。正常SAR、Flash和ALA仍按数字事务接入，后续由适配层连接实际电路。

当前八个模块已按存储和逻辑复用整理，编译文件清单为 files.f。校准测量由内部 SAR 逐次完成。

这版没有伪造测量结果，没有模拟模型，没有 testbench，也没有运行仿真。接口无人响应时会超时，不会自行生成“校准成功”或 ADC 数据。

## 文件与架构

```text
adc_digital_top
├── spi_4wire
├── digital_regs
├── clk_timing
├── flash_decode
├── cali_logic
│   ├── cal_ctrl             同文件内分区
│   ├── cal_calculation      同文件内分区
│   └── weight_regs          同文件内分区
├── ala_logic
│   ├── ala_LSB_repeat       同文件内分区
│   └── ala_calculation      同文件内分区
└── code_reconstruction
```

RTL采用Verilog写法，使用编译时系统函数$clog2求计数位宽，工具需支持Verilog-2005或更高标准。没有integer、function、ifndef或initial语句，每行一个语句，注释用于分区和说明复用条件。

全部模块共用外部 `clk_i`；`rst_ni` 低有效异步复位，释放必须满足系统同步复位释放要求。没有内部生成的新时钟。`clk_timing` 在此版只是可选的数字周期调度器，不是模拟时序发生器。

## 接口协议

除 SPI 引脚外，所有输入均属于 `clk_i` 时钟域。后续接入异步比较器时，CDC 应在适配层实现，不能把窄异步脉冲直接接到本版事务端口。

Flash、正常SAR、ALA的所有 `req_valid/req_ready` 和 `rsp_valid/rsp_ready` 均在上升沿同时为 1 时传输。请求及其参数在未接收时保持稳定；响应数据和 fault 在未接收时保持稳定。每条通道最多一个未完成事务。响应最早在请求被接受后的下一周期给出，不支持请求接受当周期的零延迟响应。

`cancel` 是取消脉冲。接入方必须撤销对应事务，清除未消费响应，不再返回该事务的迟到响应；清理完成前不得接受新请求。这样无需给每次比较增加事务标签。

### 启动与结束

- `cal_start_i`：空闲时给一个周期脉冲，启动前台校准；与采样同时到来时校准优先。
- `sample_start_i`：空闲、权重有效且数值配置有效时给一个周期脉冲，启动一次采样事务。
- `sample_ready_o`：允许接收单次采样请求。
- `busy_o`：整个数字流程忙。忙时新命令不排队，记录错误。
- `cal_done_o`：校准结束脉冲，成功与否查看 `weights_valid_o` 和错误状态。
- `frame_done_o`：一次采样流程结束脉冲，包括失败情况。
- `code_valid_o`：新输出有效脉冲；只在成功完成重构时给出。
- `code_o`：16 位偏移二进制结果，保持到下一次有效输出。

当前不设置结果输出反压；下游必须能够接收 `code_valid_o` 脉冲，或者通过 SPI 读取最新结果与帧计数。顶层串行执行，当前帧重构结束前不会覆盖其 SAR 码或 ALA 统计。

### Flash 和现有正常 SAR

流程为 Flash 请求、接收温度计码、译码、正常 SAR 请求、接收低 18 位符号码。

`flash_thermometer_i[0]` 对应最低阈值，`[2]` 对应最高阈值；输入高于阈值输出 1。接受 `000/001/011/111`，分别译为 `00/01/10/11`。其他模式判为错误，不在初版中增加气泡修正。

`sar_flash_code_o` 是接入现有 SAR 的粗码。`sar_sign_code_i[17:0]` 是 main[17:0] 的**重构符号编码**，不是未经解释的比较器原始位，也不是普通 18 位二进制数。位为 1 表示在本版重构中贡献 +Wi，位为 0 表示贡献 -Wi。

本版把 `{flash_code, sar_sign_code_i}` 组成 main[19:0] 的符号向量，并计算 `sum((2*bit-1)*Wi)`。这一约定是数字接口合同，不代表任意 SAR 开关方案都会天然满足。后续接入时，若现有 SAR 存在位反相、顺序差异、半权步进、常数项或不同的 Flash 对应关系，必须在适配层转换，必要时修改重构入口；不能直接接一个未知含义的 20 位原始码。

主 CDAC 正常转换结束状态、输入采样保持及 Flash 与 SAR 的模拟配合，均由未来测量/接口层保证。

### 校准内部 SAR 与数字命令

校准专用SAR位于 cali_logic 内，不复用正常SAR，也不从外部接收已重构测量码。

顶层校准接口：

| 接口 | 含义 |
|---|---|
| cal_cmp_req_o | 单周期比较请求，由内部SAR发出；接入层必须接收，不采用ready反压 |
| cal_cmp_done_i | 当前比较完成的单周期数字脉冲，与clk_i同步 |
| cal_cmp_result_i | 随完成脉冲提供的一位判决 |
| cal_phase_cmd_o | 数字阶段码，0 为非采样与转换阶段，1 为采样，3 为转换 |
| cal_bp_cmd_p_o | 正阵列20个位电容的选择码，共40位 |
| cal_bp_cmd_n_o | 负阵列20个位电容的选择码，共40位 |

每个位电容占2位：`[2*i+:2]`。00表示共模M，01表示正参考P，10表示负参考N，11保留。这是数字命令编码，不是参考电压本身。正负阵列由模块同步产生配对控制，测量及保存的是组合差分权重。

cal_cmp_done/result必须属于当前请求，响应最早在请求发出后的下一周期；接入层负责比较器实际触发、结果同步及滤除旧响应。响应期间不得改变判决。超时后先恢复共模再释放校准控制，旧完成脉冲不得污染下一次校准。

内部流程包含预置、采样等待、目标位激励、建立等待、逐位比较、低位试探/恢复、量化结果扫描、方向及重复次数推进、平均、高位还原、写权重和共模恢复。新增ALA电容在校准期间必须由后续顶层物理映射保持固定状态，不运行ALA。

每位按默认PAIR_LOG2=5执行32组正反向测量，共64次方向量化；14位共896次方向量化。每次方向量化有多次比较请求，896不是比较器请求总数。

低六位按FRAC_BITS生成1/2/4/8/16/32的标称参考权重；更高位使用此前已经校准的权重。内部ST_SCAN按实际逐位动作完成单次结果重构，并根据方向直接累加到sum_q，不需要外部提供测量码或读取参考权重。

最终平均为 `sum(Dpositive-Dnegative)/64`，加半步后右移。b18激励中扣掉W17，平均后加回W17；b19扣掉W17和W18，平均后依次加回二者。结果要求为正且在存储范围内。

高十四位权重寄存器保存在模块内部；校准过程中内部独占权重选择通路，空闲后再开放外部读口给数字重构和SPI。新校准清除高位有效标志，全部成功才置weights_valid。

本次顶层固定PAIR_LOG2=5、SAMPLE_CYCLES=8、SETTLE_CYCLES=4、PARK_CYCLES=4；CMP_TIMEOUT接顶层TIMEOUT_CYCLES，WAIT_W由等待配置自动推导，当前默认17位。它们是暂定数字等待周期，后续根据模拟建立时间调整，不表示已经实现物理采样/AZ波形。

模块error[0]为比较超时，error[1]为算术溢出，error[2]为无效参考、结果非法、平均异常或状态异常；顶层统一映射到errors[6]。校准结束由cal_release_ready_o通知顶层；成功与否结合weights_valid和error判断。

### ALA 事务

`ala_repeat_o=1` 为 LSB_REPEAT，`=0` 为 LSB_AVERAGE；仅在 ALA 请求有效时解释。`ala_index_o` 为本次额外比较序号，从 0 开始。默认总比较次数 N=10，搜索与平均共用预算。

未来接入方必须遵守：

1. index=0 开始前将额外电容准备到 ALA 初始状态，保持主 CDAC 的正常转换最终状态。
2. repeat=1：比较当前残差，以该判决执行一次等权搜索步，然后返回判决。响应表示该步已完成，下一次请求可安全继续。
3. 判决 1 编码为 +1，判决 0 编码为 -1。搜索等效残差满足 `r_next=r-D*W_ALA`，r 与数字输出残差采用同一极性。
4. 两次搜索判决翻转后，包含翻转判决的搜索步仍已执行；后续请求 repeat=0。
5. repeat=0：保持全部 CDAC 状态，只比较，不再执行搜索步。
6. 后续判决再翻转也不返回搜索阶段。

本模块输出 S=search_sum、A=avg_sum、M=avg_count。计算模块无需保存 10 次完整判决序列。

边界策略：若 N 次用完仍未进入平均，或者翻转恰好发生在最后一次，则 M=0。此版采用**仅保留搜索修正 S*W_ALA、跳过平均项**，并置 errors[7] 提示。它是初版选定的退化处理，不是论文式(11)在 M=0 时的定义，也不保证论文所给降噪性能。

## 数值尺度与重构

建议保持默认 WEIGHT_W=32、FRAC_BITS=8。代码支持 WEIGHT_W<=32，要求 FRAC_BITS>=0、FRAC_BITS<=16、WEIGHT_W>=FRAC_BITS+7；实际最大权重必须留足有符号正数范围，不能只依赖最小宽度条件。

用 U 表示归一化权重单位，存储整数 `Wi_q=round(Wi/U * 2^FRAC_BITS)`。U 不是自动等于输出 ADC LSB，也不是自动等于伏特。

`ALA_STEP` 必须是单个搜索步在**与主权重相同的残差坐标**中的有效权重，采用同一 Q 格式。不能直接把它认作默认的 W0；差分/单端尺度及桥接衰减必须在后续电容网络确定后换算。

重构模块从接受start_i起到done_o有效为止，直接使用顶层保持的符号码、ALA统计、ALA使能、步长、增益和偏移。当前顶层在本帧完成前保持sign_code_q，下一次ALA启动前保持统计，忙时拒绝数值配置改写。独立复用code_reconstruction时，调用方也需要满足这项稳定输入条件。

重构执行：

```text
normal_q = sum((2*sign_bit-1)*Wi_q)
corrected_q = normal_q - S*ALA_STEP - trunc_toward_zero(A*ALA_STEP/M)
signed_code = round_nearest_away(corrected_q*GAIN_Q16 / 2^(FRAC_BITS+16)) + OFFSET
output = saturate(signed_code, -32768, 32767) + 32768
```

M=0 或关闭 ALA 时不执行平均除法；关闭 ALA 时同时跳过搜索修正。平均项在存储最小位处向零截断；最终输出使用最近舍入，半值向远离零方向处理。

重构按位读取 20 个权重；搜索修正和平均分子采用最多 10 次小范围重复加减；平均除法为 NUM_W=WEIGHT_W+4 周期的移位减法，不推导通用除法器。输出缩放使用一套乘法运算，非缩放阶段隔离其变化的数据输入。没有为每个位实例化乘法器。

GAIN_Q16 表示“每个 U 对应多少最终输出码”的无符号 Q16 增益，不是给已经带 FRAC_BITS 的整数再直接乘一个未经缩放的系数。OFFSET 为最终有符号码单位的补偿。

ALA_STEP 和 GAIN_Q16 复位为 0，必须写入有效数值后才能转换，避免给尚未完成的模拟电路擅自指定绝对比例。允许先关闭 ALA，仅配置增益检查正常重构。

示例只说明编码：若经确定 1U 对应 0.5 个输出码，GAIN_Q16=32768；若 ALA 步长为 2U 且 FRAC_BITS=8，ALA_STEP=512。这些不是两篇论文的实际参数。

## SPI 与寄存器

SPI 为模式0，MSB先行。每次 CS 拉低只传一帧，共48位：命令8位、地址8位、数据32位。命令 0x80 为写，0x00 为读；其他命令不写寄存器。多字连续读写和其他模式暂不实现。

SPI 在 clk_i 域过采样；约束 clk_i>=8*SCLK，并确保 CS 建立/保持及相邻帧高电平时间至少4个 clk_i 周期。MOSI 必须满足模式0时序。MISO 是独立输出数据，CS高时输出0；板级需要共享三态总线时由IO层控制输出使能。

| 地址 | 名称 | 功能 |
|---|---|---|
| 0x00 | ID | RO，0xADC01601 |
| 0x04 | CONTROL | bit0使能；bit1 ALA使能；bit2校准启动脉冲；bit3单次采样脉冲；bit4清错脉冲；bit5周期采样使能 |
| 0x08 | STATUS | bit0忙；bit1整表权重有效；bit2数值配置有效；bit3至少有一次输出；bit15:8错误状态 |
| 0x0C | ALA_N | RW，1..10，默认10 |
| 0x10 | ALA_STEP | RW，与权重同尺度的ALA步长 |
| 0x14 | GAIN_Q16 | RW，输出缩放 |
| 0x18 | OFFSET | RW，32位补码输出偏移 |
| 0x1C | LAST_CODE | RO，最近一次16位输出 |
| 0x20 | FRAME_COUNT | RO，成功输出累计数，32位自然回绕 |
| 0x24 | WEIGHT_ADDR | RW，0..19 |
| 0x28 | WEIGHT_DATA | RO，空闲时的所选权重 |
| 0x2C | WEIGHT_VALID | RO，空闲时所选权重有效 |
| 0x30 | PERIOD | RW，周期采样间隔，单位clk_i，默认1000 |

CONTROL 的配置位按整字更新；例如保留使能和ALA并启动校准写0x07，启动单次采样写0x0B。专门写0x10只清除错误，不改变配置。其他只读/未映射地址写入、非法比较次数、非法周期或忙时配置写入均拒绝并记录错误。

SPI内部wr_data_o兼作32位接收移位寄存器，仅wr_en_o=1时与addr_o共同提交有效写入。寄存器模块按wr_en_i接收，因此外部SPI写入时机保持原定义。

SPI读数据在地址接收后取一次快照。软件先设置 WEIGHT_ADDR，再读 DATA/VALID。忙时权重调试读取返回0且无效；不会与重构争用读地址。

复位后建议：配置增益、ALA步长和其他参数；启动校准，按内部SAR发出的逐次请求提供判决；等待权重有效；启动单次采样并依次提供Flash、SAR、ALA事务响应；查看 code_valid_o。连续模式忙时到来的周期请求不排队，置错误位；必须把周期设置得足够长。

## 错误位

| 位 | 意义 |
|---|---|
| 0 | 忙时命令、非法寄存器写入或同时启动冲突 |
| 1 | 未使能、数值配置无效或权重未校准时请求采样 |
| 2 | Flash超时、fault或非法温度计码 |
| 3 | 正常SAR超时或fault |
| 4 | ALA超时或fault |
| 5 | 重构输入或权重无效 |
| 6 | 校准比较超时、算术溢出、参考无效或权重结果非法 |
| 7 | 本帧ALA没有平均样本，使用搜索项退化修正 |

错误位保持到清错。Flash、正常SAR、ALA对请求和响应等待分别计时；校准内部仅对每次比较完成等待计时。顶层TIMEOUT_CYCLES必须>=1。
