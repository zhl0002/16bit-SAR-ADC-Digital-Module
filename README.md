# 16 位 SAR ADC 数字模块

这个仓库按数字集成电路的设计流程组织。三个子项目各有自己的入口、输入和产物。从完整的 Verilog 设计基线出发，选取校准模块 `cali_logic` 做 RTL 功能验证，再把验证版本综合成标准单元电路。

| 顺序 | 子项目 | 完成的工作 | 主要产物 |
| --- | --- | --- | --- |
| 01 | [Verilog](01-Verilog/) | 整理完整数字设计与模块接口，建立源码基线 | 八个 Verilog 模块、编译清单和三份阅读指南 |
| 02 | [RTL 设计与验证](02-rtl-design/) | 对 `cali_logic` 建立自检用例，检查控制、校准和权重读出 | 已验证 RTL、七份 testbench、九组回归记录 |
| 03 | [逻辑综合](03-logic-synthesis/) | 把第 02 阶段的模块映射成标准单元，并检查试综合面积和内部时序 | 门级网表、10 ns 试用约束和结果摘要 |

第 01 阶段覆盖完整数字模块。第 02、03 阶段以独立的 `cali_logic` 为对象。后续的形式等价验证将核对第 03 阶段的网表和第 02 阶段的 RTL 是否保持同样的功能。
