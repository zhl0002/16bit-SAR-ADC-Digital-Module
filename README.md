# 16 位 SAR ADC 数字模块

这个仓库按数字集成电路的设计流程组织。六个子项目各有自己的入口、输入和产物。从完整的 Verilog 设计基线出发，选取校准模块 `cali_logic` 做 RTL 功能验证，再综合成标准单元电路，检查 RTL 与门级网表的逻辑等价性，随后加入扫描链并验证测试向量，最后将扫描版实现为可交接的标准单元版图。

| 顺序 | 子项目 | 完成的工作 | 主要产物 |
| --- | --- | --- | --- |
| 01 | [Verilog](01-Verilog/) | 整理完整数字设计与模块接口，建立源码基线 | 八个 Verilog 模块、编译清单和三份阅读指南 |
| 02 | [RTL 设计与验证](02-RTL-Design/) | 对 `cali_logic` 建立自检用例，检查控制、校准和权重读出 | 已验证 RTL、七份 testbench、VCS 回归脚本、用例结果与 Lint 报告 |
| 03 | [逻辑综合](03-Logic-Synthesis/) | 把第 02 阶段的模块映射成标准单元，并检查试综合面积和内部时序 | 综合 Tcl、门级网表、SDC、DDC、SVF 和原始结果报告 |
| 04 | [形式等价验证](04-Formal-Verification/) | 用 Formality 对比第 02 阶段的 RTL 与第 03 阶段的网表，706 个比较点全部通过 | 复跑 Tcl、输入校验清单和原始等价报告 |
| 05 | [可测性设计（DFT）](05-Design-for-Test/) | 插入 584 单元扫描链，验证功能模式，生成并回放 349 个固定型故障向量 | 扫描网表、SPF、SCANDEF、插入指导 SVF、串行 STIL、故障表和验证报告 |
| 06 | [布局布线（P&R）](06-Place-and-Route/) | 用 ICC2 完成平面规划、布局、时钟树、布线和优化，进行布线后等价验证 | 试实现 SDC、复查 Tcl、结果摘要与本地交接文件说明 |

第 01 阶段覆盖完整数字模块。第 02 至 06 阶段以独立的 `cali_logic` 为对象。
