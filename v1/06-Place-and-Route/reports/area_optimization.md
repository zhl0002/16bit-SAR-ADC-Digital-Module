# cali_logic 布局布线面积优化

以已收敛的 `cali_logic/final_routed_10ns` 为基线，通过 ICC2 压缩核心、重建电源与布线并复查时序。优化分支沿用原 RTL、扫描顺序和 10 ns 试实现约束。最终选中 `u89_seed`，边界面积缩小 **36.08%**。

## 操作与目的

| 工作 | 软件与操作 | 目的与结果 |
| --- | --- | --- |
| 试探压缩范围 | ICC2 对不同核心利用率建立独立候选，运行布局、时钟树与布线 | 观察边界缩小时的时序、合法性和供电结果，保留原版作为对照 |
| 保持扫描顺序 | 在 ICC2 关闭扫描链重排与重新分组，用 Formality 复查两种模式 | 纠正早期候选的扫描链变化，沿用 DFT 扫描顺序 |
| 压缩原有布局 | 在复制的 NDM 上记录原单元位置和朝向，目标利用率设为 89%，边距 7.5 µm。按比例移动单元并合法化 | 保留邻近单元的分布，实际核心利用率达到 89.77% |
| 重建物理连接 | 重建 PG 环、网格和行轨，放置端口，重走时钟和信号线。启用 CCD，填充后再优化 | 在新几何边界上重新闭合供电、布线与时序 |
| 选择通过版 | 对照 DEF 尺寸、ICC2 验收、GDS 层次及 Formality 全模式报告 | 从 23 个有面积数据的候选中选出通过全部验收的最小版本 |

## 最终结果

| 指标 | 基线 | 选中候选 `u89_seed` |
| --- | ---: | ---: |
| 版图边界 | 423.92 µm × 423.20 µm | 339.72 µm × 337.56 µm |
| 边界面积 | 179,402.94 µm² | 114,675.88 µm² |
| 核心利用率 | 57.67% | 89.77% |
| 网表单元 / 填充单元 | 3,326 / 4,199 | 3,338 / 414 |
| 网表单元面积 | 93,920.90 µm² | 94,027.35 µm² |
| 最差 setup / hold 裕量 | +0.1087 / +0.5845 ns | +0.0151 / +0.3134 ns |

最终 ICC2 布线违规和开路均为 0，布局合法性、PG 连通、PG DRC 与内部 LVS 检查通过。GDS 层次和标准单元结构核验通过。Formality 保持 `scan_en` 自由，707 个比较点通过。更小的 90% 和 90.5% 原布局压缩分支做过局部驱动 ECO，最差 setup 仍为 −0.0947 ns 和 −0.4945 ns。

## 工程文件和交接

| 文件 | 作用 |
| --- | --- |
| [`area_sweep.csv`](area_sweep.csv) | 记录各候选的实际尺寸、面积、setup/hold 及检查结果。缺失值表示该候选未取得该项结果 |
| [`compact_routed_block.tcl`](../scripts/compact_routed_block.tcl) | 从原版 NDM 复制工作库，复现坐标压缩、电源重建、重布线和候选验收。输出候选 NDM、DEF 与报告 |
| [`measure_area_trials.py`](../scripts/measure_area_trials.py) | 从本地候选 DEF 和 ICC2 报告提取面积与检查状态。`passes` 表示 ICC2 工程检查通过，交付等价与 GDS 核验另行记录 |
| `compact.ndm` 中的 `cali_logic/packed_final` | 最终紧凑版块。本地 `delivery` 保存 GDS、DEF、网表、约束及提取文件，`reports/final` 保存原始报告 |

压缩 Tcl 由 `icc2_shell -f` 执行。`AREA_SOURCE_NDM` 指向原始 `cali_logic_trial.ndm`，且原参考库路径须可解析。`AREA_RUN_DIR` 为新目录，`AREA_TLU` 和 `AREA_LAYER_MAP` 指向本地试用 RC 和映射。选中版参数为 `AREA_UTIL=0.89`、`AREA_OFFSET=7.5`。`AREA_CORES` 指定可用核数。用 `measure_area_trials.py` 读取复跑结果时，在候选目录的 `exit_status` 文件保留 ICC2 Shell 退出码。

本轮使用试用 RC 和典型角 10 ns 条件。版图压缩量主要来自核心空隙减少，100 µm × 100 µm 的面积目标、晶圆厂物理规则和正式时序签核仍待完成。
